# 教培资讯平台 — 安装与部署说明

## 一、这是什么

教育培训行业资讯聚合平台：收录权威官网 / 微信公众号名片，自动抓取新闻文章，并提供 AI 对话助手。

## 二、环境要求

- Node.js 18 或更高版本（<https://nodejs.org>）
- 无需数据库，数据以 JSON 文件存储

## 三、启动步骤

### 1. 配置 AI（可选，跳过也能运行）

- 复制 `server/.env.example` 为 `server/.env`
- 填入你自己的 DeepSeek / OpenAI 兼容接口密钥
- 不配置时，AI 会降级为「本地智能匹配」模式

### 2. 安装依赖

```bash
npm run install:all
```

（等价于分别在根目录、server、client 各执行一次 `npm install`）

### 3. 启动

```bash
npm run dev
```

- 后端：http://localhost:3001
- 前端：http://localhost:5173

### 4. 打开 http://localhost:5173 即可使用

- 应用启动即**自动以管理员身份进入**，无需注册或登录

## 四、注意事项

### 1. 数据存储

- 所有数据以 JSON 文件保存在 `server/src/data/` 目录
- 首次启动会自动生成默认分类和默认网站
- `articles.json` 是打包时自带的爬取结果（种子数据），删除后重新触发「内容抓取」即可重新生成

### 2. 安全（重要）

- **不要**把 `server/.env`、`server/src/data/settings.json`、`users.json`、`chats.json` 提交到公开仓库或发给别人
- 这些文件包含 API 密钥、账号信息、私密对话记录
- 本项目打包时已剔除这些敏感文件

### 3. 内容抓取

- 在「管理后台 → 内容抓取」标签页即可触发爬虫（已对所有用户开放，无需管理员限定）
- 微信公众号来源不会被自动抓取（微信反爬），仅提供跳转入口

### 4. 关于部署形态

- 本平台定位为**本地单用户工作台**，数据只在本机 JSON 文件中
- 已移除「资源广场」与注册 / 登录功能，无需云端部署即可独立使用

## 五、常见问题

- **端口被占用**：修改 `server/.env` 中的 `PORT`，并同步修改 `client/vite.config.ts` 里的代理端口
- **AI 不回复**：检查 `server/.env` 的 `OPENAI_API_KEY` 是否正确
- **前端加载失败**：确认后端已在 3001 端口启动
