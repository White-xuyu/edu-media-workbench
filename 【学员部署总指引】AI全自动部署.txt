【本包包含哪两个项目】
1) 信息聚合平台（教培资讯聚合 + AI 对话）
   - 位置：信息聚合平台
   - 部署后地址：前端 http://localhost:5173 ，后端 API http://localhost:3001
   - 自带安装文档：信息聚合平台/INSTALL.md （请照它做）
2) 教培新媒体面板（选题/文案/封面/合规/全自动演示）
   - 位置：教培新媒体面板
   - 部署后地址：http://localhost:4000
   - 自带部署指南：教培新媒体面板/_AI部署指南-请先阅读.md （请照它做）

【请按以下步骤执行。你具备命令行执行能力的话直接做；遇到"需要密钥"先停下来问我。】
0. 先通读两个子项目各自的文档（INSTALL.md 与 _AI部署指南-请先阅读.md），了解各自结构与端口。
1. 确认本机已安装 Node.js 22.x（同时满足两个项目的 Node 18+ 要求）；没装就帮我装好。
2. 部署信息聚合平台：
   - 进入 信息聚合平台
   - 执行它 INSTALL.md 里的 `npm run install:all` 与 `npm run dev`
     （这条命令会同时起前端 5173 与后端 3001，无需数据库，数据存 JSON 文件）
   - AI 密钥可选：不填也能跑，会降级为"本地智能匹配"；要填就复制 server/.env.example 为 server/.env 再填。
3. 部署教培新媒体面板：
   - 进入 教培新媒体面板
   - 执行《_AI部署指南-请先阅读.md》里的步骤：npm install → npx playwright install chromium →
     编辑 config.json 填入"我"的 llm.apiKey/baseUrl/model（这一步需要问我拿 key）→ node server.js（端口 4000）
   - 注意：config.json 里的 publish.* / obsidian.* / platform.envPath 是可选高级功能用的本机路径，
     首次部署保持默认即可，不要改、也不要因它们报错而卡住。
4. 两个服务都以后台/常驻方式启动，确认都没有崩溃、都成功监听端口。
5. 验证：用 curl 或浏览器确认 http://localhost:4000 与 http://localhost:5173 都能返回正常页面（状态码 200）。
6. 把两个网址告诉我，并说明哪些功能需要额外配置（真发小红书 / 接知识库 / 接信息聚合平台高级联动可跳过）。

【验收标准】
- 浏览器打开 http://localhost:4000 ：能看到教培新媒体面板（灵感/创作/发布/合规/演示 菜单）。
- 浏览器打开 http://localhost:5173 ：能看到信息聚合平台，能注册/登录（首个注册账号自动成为管理员）。
- 两个站点都能稳定访问，不依赖对方也能各自打开（信息聚合平台未启动时，面板选题会自动回退到内置示例素材）。
