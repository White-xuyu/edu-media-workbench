# 教培新媒体工作台

一个**跑在本地**的新媒体运营面板，把教培行业新媒体专员的日常工作流——找选题、写文案、做封面、发小红书、过合规——收进一个网页界面里。

所有数据存在本机 JSON 文件里，不需要数据库，不需要服务器，不依赖任何云服务。

---

## 它解决什么问题

教培新媒体专员的日常通常是「散」的：政策资讯在一个网站看、选题靠拍脑袋、文案在聊天框里生成、封面用设计工具现做、发之前还要手动过一遍违禁词。

这个工作台按**业务流程**把这些串成一条线：

```
灵感输入  →  内容生产  →  发布分发  →  合规风控
```

| 模块 | 做什么 |
|---|---|
| 灵感输入 | 选题日历、行业资讯聚合（可对接资讯平台，抓取本地教育政策动态） |
| 内容生产 | AI 选题生成、文案生成、白皮书物料、封面渲染（7 套 HTML 模板本地出图） |
| 发布分发 | 小红书自动发布 / 存草稿 / 一键下载手动发；发布前频次护栏 |
| 合规风控 | 违禁词清单、发布前合规自检、违规记录留档 |

---

## 技术栈

- **后端**：Node.js + Express（端口 4000），同时托管前端静态资源
- **前端**：原生 HTML / CSS / JavaScript，无需构建步骤
- **浏览器自动化**：Playwright + Chrome DevTools Protocol（CDP）
- **封面渲染**：HTML 模板 + Playwright 本地截图，不是 AI 生图
- **数据存储**：本地 JSON 文件，零数据库

## 快速开始

### 1. 环境要求

- Node.js 18 或更高版本
- 一个可用的大模型 API Key（DeepSeek 或 OpenAI 兼容接口）——AI 相关功能需要

### 2. 安装依赖

```bash
npm install
```

### 3. 创建配置文件

仓库里的 `config.json` 未包含（它存放你的私密 Key）。复制模板：

```bash
cp config.example.json config.json
```

然后打开 `config.json`，把 `llm.apiKey` 换成你自己的 Key：

```json
{
  "llm": {
    "apiKey": "你的 Key",
    "baseUrl": "https://api.deepseek.com",
    "model": "deepseek-chat"
  }
}
```

### 4. 安装浏览器内核（仅发布功能需要）

```bash
npx playwright install chromium
```

### 5. 启动

```bash
node server.js
```

打开 **http://localhost:4000** 即可使用。

> 前端由后端直接托管，不需要另外起 Vite 或做任何构建。

## 关于小红书发布

发布模块使用 **CDP（Chrome DevTools Protocol）** 连接你本机已登录的真实浏览器，而不是新建一个自动化浏览器——目的是尽量复用你日常账号的真实环境。

在面板里点击「打开发布专用浏览器」会用调试端口（默认 9222）启动浏览器，首次需扫码登录一次，登录态会被保留。

**发布方式建议**

| 方式 | 说明 |
|---|---|
| 一键下载（推荐） | 导出成图 + 文案，手动发。零风险 |
| 存草稿 | 自动填入标题正文图片，存进草稿箱，你人工确认后发布 |
| 直接发布 | 自动走完发布流程，适合批量场景 |

面板内置发布频次护栏（默认两次发布最小间隔 60 分钟、两次存草稿最小间隔 15 分钟），避免因操作频繁触发平台限流。**请遵守各平台的社区规范与发布频率要求。**

## 目录结构

```
├── server.js              # 后端服务主文件（API + 静态托管）
├── xhs-publish.js         # 小红书发布脚本（Playwright + CDP）
├── config.example.json    # 配置模板（复制为 config.json 使用）
├── campuses.json          # 校区关键词配置
├── prompts/               # 提示词模板
├── public/                # 前端页面与静态资源
├── covers/                # 封面 HTML 模板（7 套）
├── dict/                  # 营销词库
└── output/                # 运行期产物（封面、发布记录、违禁词库）
```
